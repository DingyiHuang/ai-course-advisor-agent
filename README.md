# AI课程顾问 Agent

OPC“首届软件与智能体开发大赛”的统一赛题作品。项目面向学生/家长、教师、机构/企业三类用户，目标是在严格资料边界内完成身份澄清、需求采集、班型推荐、课程问答、报名引导与多轮会话。

当前为TASK-05候选v1：项目已具备类型化知识、确定性规则、真实模型会话、响应式聊天界面、结构化推荐卡、机构服务、错误恢复、一次性测试故障与实际状态Markdown导出。当前自动回归为16个测试文件、141条测试通过。2026-07-23参赛人浏览器复验的总体结论为失败，证据后代码加固尚待重新复验；官方25组尚未执行，不得提前视为正式验收通过。

## 本地运行

环境要求：Node.js 20.9 或更高版本、npm。

```bash
npm install
cp .env.example .env.local
npm run dev
```

浏览器访问终端打印的`Local`地址，默认是`http://localhost:3000`；若端口占用，以实际端口为准。真实模型配置由参赛人本人保存在本地`.env.local`，前端不会读取或直接调用密钥。

页面提供学生/家长、教师、机构/学校三个快捷入口和自由输入。快捷入口设置明确身份；“我想学AI”等模糊输入仍先进入身份澄清。推荐后可点击“继续咨询该班”进行多轮追问，也可返回菜单、查看全部课程或重新开始。

只有地址包含`?test=1`时才会显示测试模式，例如`http://localhost:3000/?test=1`。“模拟模型失败”只影响下一次模型请求；失败后故障自动清除，点击“重试原请求”恢复正常调用。普通URL不会显示该控件。

点击页头“导出 Markdown”会按当前实际消息和状态下载证据文件，内容包括上海时间、会话编号、用户与AI消息、身份、约束、当前班型/服务、推荐、实际来源、测试模式和错误状态，不生成虚构对话。

## 项目边界

- 学生课程只使用素材A。
- 教师个人培训只使用素材B。
- 平台、会员和机构服务只使用素材C。
- 确定性代码负责筛选、日期、费用、前置条件、状态与来源拼接。
- LLM负责面向用户的正文和推荐理由措辞，不得用关键词返回整段固定课程答案。
- 原始 Word、素材目录、环境变量和录屏文件不得进入公开仓库。
