# 使用说明

## 当前版本

当前为TASK-05候选v1。页面已经接入真实`POST /api/chat`，支持学生/家长、教师、机构/学校三类身份，自由输入、身份澄清、多轮约束采集、推荐卡、机构服务卡、来源、异常恢复、测试模式和Markdown导出。16个测试文件、141条自动测试以及类型检查、ESLint和生产构建已通过。参赛人浏览器复验已经执行但总体结论为失败；证据后的代码加固尚待重新复验，不能据此写成全部验收通过。

## 本地启动与访问

环境要求为Node.js 20.9或更高版本及npm。在项目根目录安装依赖后启动开发服务器：

```bash
npm install
npm run dev
```

终端会打印实际地址，默认是`http://localhost:3000`。若3000端口已经占用，Next.js会自动选择其他端口，应以本次终端的`Local`地址为准。不要把`.env.local`、密钥、请求头或模型地址复制到截图、测试记录或对话导出中。浏览器只调用本项目服务端接口，不直接接触模型密钥。

## 三类身份与自由输入

打开首页后可点击“学生/家长”“教师”“机构/学校”快捷入口。快捷入口是显式身份选择，会清除另一个资料域的旧状态。也可以直接在自由输入框描述需求；例如“我想学AI”“我想给孩子看看课程”等身份不清楚的句子，应由系统先追问身份，不能直接给课程推荐。

学生或家长建议提供所在城市、可参加营期、线上/线下偏好、能否出行及是否需要回放。学生结构化约束采用封闭枚举：地区只保存北京、上海、广州或其他城市，北京区县统一归一为北京；营期只保存第一、第二、第三期；授课形式只保存线下、线上或均可，录播回放不是授课形式。形成至少两个有效约束后，系统从素材A的真实组合中推荐1—2项。广州没有学生线下班；广州家长要求线下时，应先询问能否前往北京或上海，明确均不便出行后才可考虑同一已确认营期的线上班。

教师建议提供当前基础或目标等级、能否在工作日连续脱岗、可参加时间、城市及L2/L3前置状态。零基础映射L1，不能连续脱岗优先周末研修。前置未满足时不会引导直接缴费，而是提供低一级或能力测评/同等项目路径。教师个人费用只来自素材B，不使用学生退款或机构报价。

机构或学校可咨询会员权益、企业培训、学校采购、基础Agent、AI Web应用和企业知识库/RAG。机构流程只使用素材C，不进入个人班型推荐。学校20人采购的资料口径是“项目总价5万元起”，不得出现教师个人价2980元。

## 推荐卡与连续追问

推荐卡显示完整产品名称、日期、地点/平台/授课方式、标准费用、本次实际适用费用、与你已确认约束逐项对应的动态理由、程序追加来源，以及“继续咨询该班”。点击“继续咨询该班”后，页面顶部与侧栏会显示当前班型；随后可继续问“什么时候上课”“第5天学什么”“需要带电脑吗”“费用包含什么”等，系统会继承当前班型。

页面中的追问选项和操作按钮来自API结构化字段，不通过解析AI正文关键词驱动状态。“查看全部课程”使用独立目录动作；“返回菜单”清除当前身份与业务状态但保留页面可见记录；“重新开始”清除本次页面消息与服务端会话状态并生成新的会话编号。班型规模和最低开班人数不是实时余位，页面不会把它们解释为剩余名额。

## 输入与错误恢复

空输入会在前端提示且不调用API。单次输入最多500字，输入区持续显示字数；超过500字时需先精简。只有特殊符号的输入会收到可理解的输入错误，不应导致页面崩溃。发送后立即显示“正在核对约束、课程事实与资料来源”，同时禁用输入和按钮，避免重复提交。

模型超时、网络异常、非法JSON或接地校验失败只显示脱敏提示，不展示堆栈、供应商响应、环境变量或内部提示词。composer或grounding首次失败会在服务端静默重试一次，第二次仍失败才显示脱敏错误。错误卡提供“重试原请求”和“返回菜单”；同一错误只能重试一次，历史消息上的旧操作、选项和推荐卡按钮会失效，避免重复消息或卡片。重试会重发原消息并使用失败响应保留的会话状态；它不会返回固定课程答案伪装成功。AI课程顾问不得自称人工、模拟人工顾问或人工客服；需要转人工时只能说明需人工确认或联系人工顾问。

## `?test=1`测试模式

在本地地址后加入`?test=1`，例如`http://localhost:3000/?test=1`，页面顶部会出现明确的`TEST MODE`标识，侧栏显示“模拟模型失败”。普通地址`http://localhost:3000/`不得出现这些测试控件。

点击“模拟模型失败”后，页面只为下一次模型请求设置一次性故障。随后发送一条正常问题，应看到可重试的模拟失败；该故障状态在失败后自动清除。点击“重试原请求”应恢复正常模型调用，并保留故障前的身份、约束和当前班型。测试按钮本身不会生成固定课程答案。

## 导出当前对话为Markdown

侧栏可编辑“会话/测试编号”，建议25组测试依次使用`OFFICIAL-01`至`OFFICIAL-25`。点击页头“导出 Markdown”后，浏览器下载文件：

```text
AI课程顾问_<会话编号>_<YYYYMMDD-HHmmss>.md
```

导出内容只来自当前实际消息和状态，包括Asia/Shanghai导出时间、会话编号、用户输入、实际AI回答、系统状态、错误提示、当前身份、有效约束、当前班型或机构服务分类、实际推荐卡、实际使用的资料名称和章节、是否测试模式及当前异常状态。若本次尚无推荐或来源，文件会明确写“尚无”，不会虚构对话或测试结果。

## 日期口径与已知限制
