# 使用说明

## 当前版本

当前为 TASK-01 脚手架版本。首页可用于确认 Next.js 应用已经成功启动，并展示项目目标和计划服务的三类对象；课程咨询、推荐、多轮追问和模型调用尚未接入。因此当前页面不会给出价格、日期、地点或班型答案，避免把未验证内容误当成正式功能。

## 本地访问

准备 Node.js 20.9 或更高版本和 npm。在项目根目录执行 `npm install` 安装依赖，再执行 `npm run dev` 启动开发服务器。终端显示服务就绪后，使用现代浏览器访问 `http://localhost:3000`。页面显示“AI课程顾问 Agent”和“TASK-01 基础环境已就绪”即说明脚手架运行正常。

项目提供 `.env.example` 作为环境变量名称示例。复制为 `.env.local` 后再由参赛人本人填写真实值；不要把真实 API 密钥粘贴到聊天、代码、截图或提交文档中。TASK-01 不依赖模型，因此即使没有密钥，首页、静态检查、单元测试和生产构建也应正常完成。后续接入模型后，浏览器仍不会直接调用模型，所有请求经过服务端接口代理。

## 计划中的正式操作流程

正式版本打开后会先展示学生课程、教师培训、平台服务三个快捷入口，同时保留自由输入。用户可以点击入口，也可以直接描述需求。模糊表达会先进入身份澄清；身份确认后，系统只进入对应资料域。学生或教师要求推荐时，系统采集城市、日期、形式、目标等有效约束，信息充足后推荐1—2个真实班型；信息不足时继续追问，若用户不愿补充则明确说明资料不足并返回菜单。

获得推荐后，可以继续询问“这个班什么时候”“第5天学什么”“要带电脑吗”等问题。系统会继承当前班型，回答后显示使用的资料名称和章节。用户输入“重来”或使用重置操作后，旧班型和旧约束会被清除。机构用户只获得平台或合作服务介绍，不进入个人课程班型推荐。

## 计划中的测试模式

正式版本将支持在地址后加入 `?test=1` 显示测试控件。“模拟模型失败”只影响下一次请求，用于验证错误提示与重试，不会返回固定课程答案冒充成功结果。对话可导出为 Markdown，文件包含时间、测试编号、消息、身份、约束、推荐结果和来源，作为真实测试证据。

## 质量检查与已知限制

开发者可运行 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。当前仅有脚手架冒烟单测，官方25组和14组补充用例尚未运行，测试记录会如实标记为待执行。当前版本没有测试账号，也不需要登录。正式部署链接、模型、国内网络可用性和七天额度保障要到后续阶段验证；在验证完成前，不应将此脚手架链接作为最终作品提交。
