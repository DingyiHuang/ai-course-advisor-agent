# 演示视频脚本

## 托管与规格

计划录制2—3分钟连续演示。主地址使用B站公开视频，备用地址使用GitHub Release压缩MP4。北京时间7月23日18:00前开始上传，19:00前在未登录状态验证权限、声音与画面。

## 镜头规划

| 时间 | 操作 | 讲解重点 | 验收点 |
|---|---|---|---|
| 0:00—0:15 | 打开首页 | 说明服务学生、教师、机构三类用户 | 欢迎与分流 |
| 0:15—0:35 | 输入“我想学AI” | 展示系统先澄清身份，不直接推荐 | 身份澄清 |
| 0:35—1:05 | 学生路径给出城市、日期和回放需求 | 展示1—2个真实班型及逐项理由 | 推荐与约束一致 |
| 1:05—1:30 | 追问“这个班什么时候”“第5天学什么”“需要带什么” | 展示多轮继承和程序追加来源 | 三轮上下文、可定位引用 |
| 1:30—1:50 | 教师路径说明工作日不能脱岗 | 展示周末班规则和前置校验 | 教师推荐映射 |
| 1:50—2:10 | 机构询问学校采购价格 | 展示只用素材C，个人价与采购价不混 | 资料边界 |
| 2:10—2:30 | 测试模式触发下一次模型失败 | 展示错误可见、可重试 | 异常恢复 |
| 2:30—2:50 | 用同一问题的另一种问法再次提问 | 事实和来源一致、措辞不同 | 动态生成证明 |
| 2:50—3:00 | 展示导出、仓库和测试结论 | 说明证据与已知限制 | 可维护性与交付 |

正式录制前用生产环境完整走一遍，删除等待过长的镜头，但不能剪成无法证明连续多轮的片段。
