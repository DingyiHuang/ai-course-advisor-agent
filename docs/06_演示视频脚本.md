# 演示视频脚本

## 托管与规格

计划录制2—3分钟连续演示。主地址使用B站公开视频，备用地址使用GitHub Release压缩MP4。当前尚未录制、上传或验证任何视频地址；这些工作属于后续阶段，不得在TASK-05写成完成。正式视频必须在未登录状态验证权限、声音与画面，且不得录入`.env.local`、密钥、请求头、供应商响应或内部提示词。

录制前先启动本地开发服务器，以终端实际打印的`Local`地址为准。普通流程使用不带参数的首页；异常演示单独打开同一地址的`?test=1`版本。侧栏会话编号建议填写`DEMO-V1`，最后导出的Markdown应来自录像中的真实对话。

## 页面操作入口与口播要点

- 身份澄清：普通首页底部自由输入框，不先点击三类身份，直接发送“我想学AI”。
- 学生流程：欢迎区“学生/家长”或左侧身份按钮；推荐卡底部“继续咨询该班”；后续仍用自由输入框追问。
- 教师流程：页头“重新开始”后点击“教师”；用“零基础、不能脱岗”触发周末班，再追问时间和设备。
- 机构流程：重新开始后点击“机构/学校”；输入“学校计划采购20人的教师培训”，镜头停留在“项目总价5万元起”和“仅使用素材C”，确认画面没有2980。
- 广州边界：学生身份下输入“我是广州家长，第一期只想线下”，镜头必须拍到先询问能否去北京、上海或均不便出行，不能跳剪成直接线上推荐。
- 测试模式：只有`?test=1`页面侧栏存在“模拟模型失败”；普通URL不应出现。故障后使用错误卡的“重试原请求”，不要重新输入一个不同问题替代重试。
- 导出：页头“导出 Markdown”；会话编号在左侧可编辑。文件名应类似`AI课程顾问_DEMO-V1_20260723-xxxxxx.md`。
- 重置：页头“重新开始”；用于证明身份、约束、当前班型、历史和一次性故障清空。

口播明确说明职责边界：代码负责筛选、日期、费用、优惠、前置、推荐映射、状态和来源；LLM只基于本次结构化事实动态生成正文与推荐理由。教师早鸟“开课日前14日”的口径为“截止日＝开课日－14个自然日，截止当日24:00前有效”。班型规模和最低开班人数不是实时余位。
