# 需求解读与方案

## 1. 目标与成功标准

本项目为“AI课程顾问 Agent”。系统需要服务学生/家长、教师、机构/企业三类用户，在不编造资料的前提下完成身份澄清、需求采集、课程或服务介绍、多轮追问和报名引导。A级候选的内部目标是总分不低于90分，其中知识准确目标23—25分、功能体验目标27—30分；官方25组用例整体通过率目标不低于90%。

方案采用“规则确定事实与决策，LLM负责自然语言表达，程序追加来源”的混合架构。它既避免金额、日期和前置条件被模型猜测，也保留同一事实面对不同问法时的动态表达能力。

## 2. 角色与资料边界

| 身份 | 需求范围 | 唯一资料 | 严格边界 |
|---|---|---|---|
| 学生/家长 | 夏令营营期、城市、线上线下、费用、物资、退款 | 素材A | 不回答教师培训或平台会员价格 |
| 教师 | L1/L2/L3、集训/周末、前置、安排、个人费用 | 素材B | 不套用学生退款规则，不使用机构采购报价 |
| 机构/企业 | 平台权益、企业培训、学校采购、项目交付 | 素材C | 不进入个人班型推荐，不把机构价说成个人价 |

用户输入“我想学AI”“想给孩子报班”等模糊表达时，系统先澄清身份；三个入口按钮只提供快捷分流，不能替代自然语言澄清能力。跨域咨询允许切换，但必须明确告知资料域已切换。

## 3. 七步业务流程

1. 新会话展示服务范围、三个快捷入口和自由输入框。
2. 身份不明确时先澄清，未澄清前不推荐班型。
3. 推荐意图下采集城市、日期、形式、目标等约束，已提供信息不重复询问。
4. 至少形成两个有效约束后，从相应资料推荐1—2个真实班型；若用户拒绝补充或无法形成新约束，说明资料不足并返回菜单。
5. 用户追问费用、时间、地点、师资、大纲或物资时，继承当前班型，使用结构化事实回答并由程序追加资料与章节。
6. 报名意向只给出资料已有步骤；链接、电话、余位、付款状态等资料外信息明确需模拟人工确认。
7. 支持取消、重来、查看全部课程和返回菜单；重置后不得继承旧班型。

机构端不套用学生/教师推荐七步：身份澄清后先分类为会员权益、企业培训、学校采购或项目交付，仅基于素材C介绍并引导模拟人工顾问。

## 4. 技术方案

- Next.js App Router + TypeScript 提供响应式聊天界面和服务端接口。
- `lib/knowledge` 保存类型化实体和字段来源表，不使用通用扁平事实数组。
- `lib/time` 统一按 `Asia/Shanghai` 处理业务日期，支持固定时间注入。
- `lib/rules` 负责推荐映射、日期冲突、费用、优惠、前置条件和机构分流。
- `lib/llm` 拆分 classifier 与 composer；前者温度0，后者约0.6。
- `lib/citations` 根据 `usedFactIds` 从字段来源表生成尾注。
- `lib/validation` 只校验高风险金额、日期和事实编号，避免普通数字误伤。
- Vitest 覆盖知识、日期、费用、前置和推荐。Playwright不在提交前关键路径。

## 6. TASK-05可提交版本v1方案

首页采用“状态侧栏＋对话主区＋固定输入区”的响应式布局。桌面端持续显示当前身份、已确认约束、当前班型或机构服务；手机端按单列重排。三类快捷入口通过结构化`select_domain`动作明确设置身份，自由输入仍交给classifier，因此“我想学AI”“想给孩子看看课程”等模糊表达不会因页面关键词被直接分流。用户消息、AI正文、系统状态和错误提示使用不同语义样式，提交期间显示加载状态并禁止重复发送。

推荐响应新增程序生成的展示结构：完整产品名称、日期、地点或平台、标准费用、规则层计算的实际适用费用、动态逐项理由、程序来源和“继续咨询该班”。产品字段和价格来自结构化知识与规则计算；`recommendationReasons`由composer依据本次`decisionTrace`动态生成，程序校验其班型、约束键完整性、高风险金额/日期和来源禁写规则。页面不解析AI正文来决定状态。用户选择卡片后，`select_entity`只允许绑定本轮真实推荐项，多轮事实问题继承该班型。

机构卡只展示素材C服务类别、适用对象、计价规则和边界。学校20人采购应显示“项目总价5万元起”，不得显示教师个人价2980元。班型规模、最低开班人数与实时余位严格区分，推荐卡固定提醒资料未提供实时余位。

异常恢复使用原请求快照：空输入和超过500字在前端提示且不调用接口；API或模型失败只显示脱敏错误、重试和返回菜单。重试重发原消息并采用失败响应保留的会话状态，不使用固定课程答案。只有URL包含`?test=1`时显示测试标识和“模拟模型失败”，按钮通过服务端会话标志只影响下一次模型请求，失败消费后自动清除，重试恢复正常调用。

Markdown导出完全读取当前浏览器中的实际消息与服务端状态，不补写虚构对话。内容包含Asia/Shanghai导出时间、可编辑会话编号、实际用户/AI/系统/错误消息、身份、有效约束、当前班型或机构分类、推荐卡、实际来源、测试模式和当前异常状态；文件名为`AI课程顾问_<编号>_<上海时间>.md`，便于25组用例归档。

“查看全部课程”使用结构化`catalog`动作，由程序准备对应资料域的事实，仍由composer动态组织正文并由程序追加来源；“返回菜单”“重新开始”“选择当前班型”均是显式动作，不依赖正文关键词。
